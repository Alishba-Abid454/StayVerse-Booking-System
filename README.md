# StayVerse - Booking System

StayVerse is a full-stack web-based hospitality booking system developed using **ASP.NET Core MVC, C#, Entity Framework Core, and SQL Server**. The platform allows users to explore hospitality properties, make reservations, and manage their bookings through an easy-to-use interface.

The system also includes an **AI-powered chatbot** to assist users with their queries and improve their overall booking experience.

---

## Project Overview

StayVerse provides a centralized platform for managing hotel and restaurant bookings. It includes separate functionality for customers and administrators.

Customers can browse available properties, view their details, make reservations, and manage their bookings.

Administrators can manage properties, reservations, users, and other system data through an administrative dashboard.

---

## Features

### User Features

- User registration and login
- Secure authentication and authorization
- Browse available properties
- View property details
- Make reservations
- View reservation details
- Manage bookings
- Check reservation status
- AI-powered chatbot assistance

### Admin Features

- Admin dashboard
- Manage properties
- Add new properties
- Edit property information
- Delete properties
- View all reservations
- Filter reservations
- Update reservation status
- View registered users
- Monitor booking information
- Manage system data

### AI Chatbot

StayVerse includes an AI chatbot that helps users with booking-related questions and provides assistance while navigating the platform.
